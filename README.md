# PaperLeaf Web

PaperLeaf is an online PDF notebook library. Import and read as many PDFs as you need from an iPad, tablet, or desktop browser.

## Live app

[Open PaperLeaf](https://paperleaf-web.jamesalvisazarcon.chatgpt.site)

The repository contains the web app source in `index.html`. The current MVP stores imported PDFs in the browser using IndexedDB; cloud accounts and cross-device sync are planned next.
