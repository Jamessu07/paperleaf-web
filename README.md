# PaperLeaf Web

PaperLeaf is an online PDF notebook library. Import and read as many PDFs as you need from an iPad, tablet, or desktop browser.

## Live app

[Open PaperLeaf](https://paperleaf-web.jamesalvisazarcon.chatgpt.site)

This repository contains a small GitHub landing page for the deployed web app. The current MVP stores imported PDFs in the browser using IndexedDB; cloud accounts and cross-device sync are planned next.
